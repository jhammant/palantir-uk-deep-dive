How this works

Method, gaps and corrections

The rule

If it isn't in a public record we can link to, it isn't in the data. Opinion belongs in commentary, never in the dataset.

Sources

  • Contracts: Contracts Finder (keyword search for awarded notices naming Palantir, then each notice read in full) and Find a Tender (each procurement read as an OCDS record). Only awards where Palantir is the sole named supplier are counted.
  • Tax: Palantir Technologies UK, Ltd.'s full accounts at Companies House. The filings are scanned images, so figures are read by OCR and the text of every page used is kept in the repository.
  • Payments: departmental, NHS, police and council spending files, and Freedom of Information answers.
  • Influence: GOV.UK transparency releases, ACOBA advice, the lobbying register, Hansard and the registers of interests.
  • Quotes: primary sources where possible (essays, recordings, transcripts, filings); secondary reports are marked as such.

Known gaps

  • Values are what each buyer published. Some are ex-VAT and some include VAT; an award value is a ceiling or estimate, not a payment.
  • Find a Tender has no keyword search API, so procurements that appear only there are added by hand.
  • Police pilots bought through other routes may not appear in notices at all. Payments data is where they show up.
  • Press reports put the UK total close to £1bn. The difference is partly notices outside these two services and partly how extensions are counted.

Corrections

If something here is wrong, open an issue on GitHub with the source. It will be fixed and the fix noted. Palantir and every public body named are welcome to send corrections the same way.

Rebuild it yourself

python3 scripts/fetch_contracts.py refetches the contracts from the government APIs. python3 scripts/build_site.py bundles data/ into the site. Open site/index.html in a browser; no server needed.
